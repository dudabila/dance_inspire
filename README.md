# 💃 Dance Inspire

Blog pessoal sobre dança, criado para compartilhar minha trajetória como bailarina, artigos com dicas sobre o universo da dança e um canal de contato com os leitores.

Projeto desenvolvido como atividade da disciplina de **Programação Front-End**, aplicando os conceitos de HTML5, CSS3 e JavaScript.

## 🔗 Demo

https://dudabila.github.io/dance_inspire/


## ✨ Funcionalidades

- Layout responsivo (Flexbox + CSS Grid + Media Queries)
- Menu de navegação com destaque automático da página atual
- Formulário de contato com validação via JavaScript
- Efeito interativo de borda ao passar o mouse nos cards de artigos
- SEO básico (títulos e descrições únicos por página, tags semânticas, atributos `alt`)

## 📄 Páginas

| Página | Arquivo | Descrição |
|---|---|---|
| Home | `index.html` | Banner de boas-vindas, artigos em destaque, trajetória e galeria de fotos |
| Artigos | `artigos.html` | Listagem completa de artigos sobre dança |
| Minha História | `sobre.html` | Trajetória pessoal na dança |
| Contato | `contato.html` | Formulário de contato com validação |

## 🛠️ Tecnologias utilizadas

- **HTML5** — estruturação semântica do conteúdo
- **CSS3** — Flexbox, Grid, transições e Media Queries para responsividade
- **JavaScript** (Vanilla JS) — validação de formulário e efeitos interativos
- **Google Fonts** — fonte [Poppins](https://fonts.google.com/specimen/Poppins)

## 🚀 Como rodar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/dance-inspire.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd dance-inspire
   ```
3. Abra o arquivo `index.html` diretamente no navegador (ou use uma extensão como o *Live Server*, no VS Code).
